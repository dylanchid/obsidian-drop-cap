# Drop Cap

Adds stylized drop cap letters to the first paragraph of your notes.

## Install manually

Copy `manifest.json`, `main.js`, and `styles.css` (if present) into `<vault>/.obsidian/plugins/obsidian-drop-cap/`, then enable the plugin in Obsidian.

## Source

This repository contains the installed JavaScript plugin. The original TypeScript source is not available in the vault.
